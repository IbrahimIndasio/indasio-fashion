# Indasio Fashion Website

Standalone React + Vite website exported from the Figma Make project.

## Run locally in VS Code

1. Open this folder in VS Code.
2. Open the terminal in the project folder.
3. Run:

```bash
npm install
npm run dev
```

4. Open the local URL shown by Vite, usually `http://localhost:5173`.

## Create a production build

```bash
npm run build
```

The production files will be placed in `dist/`.

## Preview the production build

```bash
npm run preview
```

## Publish on your domain

You can deploy the project to Vercel, Netlify, Cloudflare Pages, GitHub Pages, or another static hosting provider. Point your domain's DNS records to the hosting provider after deployment.

### Important

Some lifestyle/product images in the current design use remote image URLs. You can replace those URLs in `src/App.tsx` with your final locally hosted brand images whenever you are ready.
